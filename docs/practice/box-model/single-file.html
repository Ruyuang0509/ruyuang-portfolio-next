盒模型 ＋ 文繞圖練習

標題文字（h2）

第一段文字。圖片用 float: left 浮到左上角之後， 這些文字會自動排到它的右邊，不需要對文字做任何設定。

第二段文字。圖片和文字之間的空隙，是圖片自己的 margin-right 撐出來的。沒有給的話文字會直接貼上去。

第三段文字，故意寫長一點。文字的量超過圖片高度之後，多出來的部分 會自動繞到圖片下方接續排列——這就是「文繞圖」，也是 float 和 flex 最關鍵的差別。捲動看看下面那張對照組卡片， 同樣的文字在 flex 版裡只會待在自己那一欄，永遠不會跑到圖片下面。

↓ 對照組：同樣的內容改用 display: flex 排成兩欄

標題文字（h2）

第一段文字。這張卡片用 display: flex 排， 圖片和文字是兩個獨立的欄。

第二段文字。欄與欄之間的距離用 gap 給， 不必在圖片上寫 margin-right。

第三段文字，一樣寫長一點。注意這一段再長，也只會在自己這一欄 往下長，不會繞到圖片下方。要雜誌式的圖文混排就用 float，要穩定的兩欄版面就用 flex。

  • 藍框＝外層 div（.card）
  • 綠框＝圖片區塊（.card__figure）
  • 紅色網底＝該元素的 padding 佔掉的空間
